# Muscle Log 人体UI素材 — 実装補足仕様（試作）

## ファイル
- `body-front.svg` 正面（胸・肩・腕・腹・脚）
- `body-back.svg` 背面（背中・肩・腕・脚）

## 注意
これらは**操作UIのための試作SVG**です。画面の人体ビジュアルの参考画像と完全一致するものではありません。Claude CodeでReactコンポーネントにインライン展開し、`g#chest` 等に選択ハンドラとキーボード操作を付与してください。SVGを`<img>`として置くだけでは、内部の部位は直接クリック操作できません。

## 部位コード
`chest` 胸（正面） / `back` 背中（背面） / `shoulders` 肩（両面） / `arms` 腕（両面） / `abs` 腹（正面） / `legs` 脚（両面）

## 操作仕様
1. タップ / クリック / Enter / Space で部位選択。
2. 左右対称パーツは一つの部位として扱い、すべて同じ選択色にする。
3. 非選択・選択・フォーカス・レポート強度をCSS変数で制御。レポートの色強度は**選択UIのカテゴリカラーとは別モード**にする。
4. `role=button`と`tabindex`のみではキー操作は自動で実現されないため、Reactでイベント処理を実装する。
5. 人体図の下に6部位のテキストボタンを常時併設する。SVGの部位が小さいときはボタンを利用できる。
6. SVGに色依存しない選択状態（選択部位名・数値・ラベル）を併記する。
7. 部位の左右は集計しない。

## 視覚コンセプト
明るい無彩色の人体シルエット、部位ごとの淡色アクセント。胸=サーモン、背中=ブルー、肩=オレンジ、腕=ライトブルー、腹=グリーン、脚=パープル。

## 受け入れ条件
- 前面・背面で選択できる部位がSPEC.mdと一致。
- 小さな画面でも代替ボタンからすべての部位を選択可能。
- 両側の腕・脚・肩を押しても単一の部位コードになる。
- キーボード操作可能で、フォーカス位置が目視できる。
- 記録内容によってSVGを改変せず、CSSの状態を変えるだけでレポート表示可能。
